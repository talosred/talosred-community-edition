How to Use

Point your LLM SDK at TalosRed CE instead of the upstream API:

OPENAI_BASE_URL=http://localhost:{{.Port}}/v1
# or in code:
client = OpenAI(base_url="http://localhost:{{.Port}}/v1", api_key="any")

Override provider per-request with the X-Provider header:

X-Provider: anthropic   # force Anthropic translator
X-Provider: gemini      # force Gemini translator
X-Provider: openai      # passthrough to OpenAI (default)
